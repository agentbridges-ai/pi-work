# Piwork BYOC Worker wrapper

This package contains the wrapper Piwork bundles into ordinary Cloudflare Workers deployed to a user-connected Cloudflare account. It does not host Apps itself.

The wrapper:

- validates an immutable per-deployment configuration;
- rejects Piwork-reserved paths;
- removes `Authorization`, `Proxy-Authorization`, `x-piwork-*`, and Better Auth cookies before calling App code;
- passes only explicitly approved Cloudflare bindings to App code; and
- reports bounded errors without exposing credentials or thrown messages.

The deployment driver uploads the bundled Worker through Cloudflare's ordinary Workers Script Upload API. Workers Static Assets use the ordinary Assets upload flow. The generated deployment must enable `disallow_importable_env`, otherwise App code could import bindings outside the wrapper's approved environment view.

## Configuration

`PIWORK_WRAPPER_CONFIG` is a plain-text binding generated by the trusted backend:

```json
{
  "schemaVersion": 1,
  "appId": "app_123",
  "allowedBindings": ["ASSETS"]
}
```

The wrapper module is bundled with the App:

```ts
import app from "./worker.mjs";
import { createAppWorkerWrapper } from "@piwork/apps-platform/wrapper";

export default createAppWorkerWrapper(app);
```

No Cloudflare account credential is part of this configuration or bundle. OAuth access remains in the trusted Piwork backend.

## Checks

The test suite runs inside Cloudflare's Workers Vitest pool:

```sh
bun run types
bun run typecheck
bun run test
bun run wrangler:check
```

See [`docs/byoc-wrapper.md`](docs/byoc-wrapper.md) for the deployment boundary.

## Local Worker tracing

The example Worker can be run in Cloudflare's local runtime with automatic
Local Explorer tracing:

```sh
bun run dev:trace
```

Wrangler prints the local URL and an `e` shortcut for Local Explorer. It is
also available at `/cdn-cgi/explorer` on that URL, with the read-only local
observability API under `/cdn-cgi/explorer/api`. This command is an opt-in
developer tool; it does not start Pi, the Pi RPC runtime, or the Piwork Web
server, and it does not use remote Cloudflare bindings.
